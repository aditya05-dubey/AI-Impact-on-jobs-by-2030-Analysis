# AI Impact on Jobs by 2030 Analysis

## Project Overview
This project analyzes the potential impact of Artificial Intelligence (AI) on jobs and industries by 2030. The analysis is based on a dataset sourced from Kaggle.

## Dataset
Dataset source: Kaggle

## Objectives
- Study the impact of AI on employment.
- Identify jobs that may be automated.
- Explore new career opportunities created by AI.
- Understand future skill requirements.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Power Bi
- Numpy
